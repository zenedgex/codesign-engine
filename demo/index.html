5 · Run it yourself

  
The same steps on your machine

  

    
Install the engine (Python 3.12 or later, macOS or Linux). No Docker or EDA tools needed for these steps.

    pip install https://github.com/zenedgex/codesign-engine/releases/download/v0.2.0/codesign_engine-0.2.0-py3-none-any.whl
codesign-engine info
    
Compile one GEMM through MLIR to the accelerator's command stream, and see its estimated cycles and area. Change the accelerator with flags.

    codesign-engine compile --m 64 --k 128 --n 128 --show-ir
codesign-engine compile --m 64 --k 128 --n 128 --rows 8 --cols 8 --dataflow os --precision 16 --spad-kb 64 --banks 4
    
Find the best compiler setting for an accelerator, list the Pareto front of all 1,272 buildable designs, and run the search loop.

    codesign-engine best-compiler --rows 32 --cols 32 --dataflow ws
codesign-engine explore --clock-ps 800
codesign-engine search --method planner --budget 20
    
Get a design for your own workloads. Write a spec with your GEMM shapes and your area, power and latency budgets; the engine searches every architecture and compiler setting, recommends the best design that fits, and exports a design package: RTL with the parameters fixed, constraints, compiler output per workload, test vectors and a testbench. Every exported program is checked against NumPy before the export reports success.

    codesign-engine spec-example > spec.json
codesign-engine design --spec spec.json --export out/
    
Budgets and rankings use T0 estimates (cycles, area, and energy from per-operation coefficients). RTL simulation, synthesis and place-and-route run in a design-partner pilot, on your EDA flow. Contact hello@zenedgex.in.
