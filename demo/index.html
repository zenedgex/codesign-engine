Try it yourself · Atelier 0.4.2 technical preview

Install the package and run it on your machine

Everything on this page comes from the published package. Install it (Python 3.12 or later, macOS or Linux; no Docker or EDA tools needed for these steps) and get the same numbers for your own requirements.

pip install https://github.com/zenedgex/codesign-engine/releases/download/v0.4.2/codesign_engine-0.4.2-py3-none-any.whl codesign-engine info

Run Qwen3-0.6B, or any Qwen2, 2.5 or 3 model from its Hugging Face config.json, on a Sutra design: time to first token, tokens per second and energy per token, by DRAM bandwidth and weight width.

codesign-engine llm --model qwen3-0.6b --rows 64 --cols 64 codesign-engine llm --hf-config config.json --engines 2 --cols 32 --dram-gbps 68.3

In a design-partner pilot, with the source tree and the simulation image, one whole Qwen3 token runs on the generated RTL, cycle-accurate: every matrix multiply and all 151,936 logits checked against the integer reference (645 of 645 bit-exact; cycle model within 0.004%). The weights are random, so this checks function and timing; correct replies with real weights need a 16-bit residual path, which is planned.

codesign-engine llm --rtl --model qwen3-0.6b --rows 64 --cols 64

Size Sutra for YOLOv8n at 640×640 with your frame-rate, area, power and latency requirements, and export the design: the RTL with its parameters fixed, a README and design.json with the estimates, and the physical-design kit with the memory list (the kit needs Docker). A GEMM spec’s export also carries the compiler output, test vectors and a testbench.

codesign-engine spec-example --network > net.json codesign-engine design --spec net.json --export out/ --flow

Or start from single GEMMs: compile one through MLIR to the accelerator's command stream, find the best compiler setting, list the Pareto front of all 1,272 buildable designs, or design for your own GEMM shapes and budgets.

codesign-engine compile --m 64 --k 128 --n 128 --show-ir codesign-engine best-compiler --rows 32 --cols 32 --dataflow ws codesign-engine explore --clock-ps 800 codesign-engine spec-example > spec.json && codesign-engine design --spec spec.json --export out/

Figures from the package are T0 estimates (cycles, area, and energy from per-operation coefficients), labelled as such. RTL simulation, synthesis and place-and-route run in a design-partner pilot, on your EDA flow. Contact hello@zenedgex.in.
